# Online Portfolio Website

Create a modern, responsive, and professional personal portfolio website for a Bachelor of Science in Information Technology student.

The portfolio should showcase my background, technical skills, projects, education, certificates, and contact information.

The website must be beginner-friendly, clean, minimalist, and easy to maintain.

Use the following technologies:

### Frontend
- HTML5
- CSS3
- JavaScript

### Local Development Environment
- XAMPP

### Database
- MySQL / MariaDB through XAMPP

### Development Tools
- Visual Studio Code
- Android Studio
- Git
- GitHub
- Figma

- Python

# 16. XAMPP Contact Form

Create an optional working contact form using XAMPP.

Use:

- HTML for the form
- CSS for styling
- JavaScript for validation
- PHP for server-side processing
- MySQL/MariaDB for storing messages
- phpMyAdmin for database management

Create a database named:

```text
portfolio_db
```

Create a table named:

```text
messages
```

Suggested structure:

```sql
CREATE TABLE messages (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL,
    subject VARCHAR(200) NOT NULL,
    message TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

The PHP backend should:

1. Connect to the database.
2. Validate the submitted information.
3. Use prepared statements.
4. Insert the message into the database.
5. Return a success or error response.
6. Never expose database passwords or SQL errors directly to visitors.

Do not fake successful database submission.
