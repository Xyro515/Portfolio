# Development Plan

## Phase 1 — Planning

- Finalize pages and sections.
- Confirm folder structure, color palette, and typography.
- Collect verified personal information and media.

## Phases 2–5 — Frontend

- Build semantic HTML pages and responsive CSS.
- Add navigation, theme persistence, filters, reveal effects, and validation.
- Present project cards without inventing links or personal claims.

## Phases 6–7 — XAMPP and PHP

- Start Apache and MySQL, then import `database/portfolio.sql`.
- Copy `php/config.example.php` to `php/config.local.php` and add local credentials.
- Test secure message insertion and the authenticated local message viewer.

## Phase 8 — Testing

- Test navigation, filters, themes, forms, database insertion, links, keyboard access, and responsive layouts.

## Phases 9–10 — Polish and Deployment

- Replace verified placeholders, add real media, confirm SEO metadata, and run accessibility checks.
- Use static hosting for the frontend only, or PHP/MySQL hosting for the complete contact workflow.
